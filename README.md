# Project Worldsmith

Project Worldsmith is a text-first, persistent world-history simulator. Players create a world, define fundamental laws, observe civilizations generate their own history, intervene as a god, and preserve alternate timelines created by changing pivotal events.

## Status

Infrastructure is established. The product brief is at Gate B: Concept; meaningful production work requires explicit gate approval.

## Working agreements

- Roadmap and issues: [Linear project](https://linear.app/lionportal1/project/project-worldsmith-edf3ba572e8c)
- Product decisions: [GitBook documentation space](https://app.gitbook.com/o/1GqExVOHS9RNozdwdymc/s/Uvdbk8sQPPjfLh2hCAtf/)
- Branches: `feature/LINEAR-ID-short-description`, `fix/LINEAR-ID-short-description`, `docs/LINEAR-ID-short-description`, or `chore/LINEAR-ID-short-description`
- Commits: Conventional Commits, for example `feat(sim): add event ledger` or `docs: establish authority record`
- Pull requests must link the Linear issue, describe tests, disclose save/data impact, and record accessibility impact.

See [CONTRIBUTING.md](CONTRIBUTING.md) and [SECURITY.md](SECURITY.md) for the full repository conventions.

## Large files

Git LFS is not required for Phase 0. Reassess before adding binary assets, generated files, or source assets larger than 50 MB; large build outputs and local saves must remain untracked.
